ALEG TUR 17g — Partial İkram/İptal Modal Tabanlı (FIX)
==========================================================

SORUN
=====

Tur 17fg'de partial ikram ve iptal için window.prompt() kullanılmıştı.
Ama prompt() bazı tarayıcılarda (özellikle PWA modunda kasiyerin tablet'i
veya Safari/iOS) ENGELLENİYOR veya görünmüyor.

Sonuç: Kasiyer 2× kalemi seçip ★ İkram'a basınca prompt çıkmıyor,
ve direkt "tüm seçili kalemler" akışına düşüyor → ikisi birden ikram!

Aynı durum × İptal için de geçerli.


ÇÖZÜM — TASARIM TUTARLI MODAL
================================

prompt() yerine güzel bir modal:

  ┌─────────────────────────────────────┐
  │  İKRAM ADEDİ SEÇ                    │
  │  am suyu                            │
  │  Toplam 2 adet var. Kaç adet ikram? │
  │                                     │
  │      [−]    1    [+]                │
  │                                     │
  │      [1]   [2]                      │ ← hızlı seçim
  │                                     │
  │  1 adet ikram edilecek,             │
  │  1 adet normal kalır                │
  │                                     │
  │  [Vazgeç]    [★ İKRAM ET]           │
  └─────────────────────────────────────┘

Avantajlar:
  ✓ Her tarayıcıda çalışır (prompt'un PWA sorunu yok)
  ✓ Görsel olarak ne yapıldığı net (1 ikram, 1 normal kalır)
  ✓ Hızlı seçim chip'leri (1, 2, 3, ... totalQty)
  ✓ +/- butonları (büyük dokunma alanı, tablet uyumlu)
  ✓ Modal görünmüyorsa Tur 17g deploy edilmemiş demektir
    → kullanıcı kolayca teşhis eder


KOD DEĞİŞİKLİKLERİ
==================

[1] app/kasa/table-detail-modal.tsx

  ▸ State eklendi:
    const [partialQtyContext, setPartialQtyContext] = useState<{
      mode: 'gift' | 'cancel';
      orderId: string;
      itemId: string;
      productName: string;
      totalQty: number;
      qty: number;
    } | null>(null);

  ▸ ESC handler'a partialQtyContext eklendi.

  ▸ ★ İkram butonu:
    Önceki: window.prompt(...) → bazı tarayıcılarda çalışmıyor
    Sonraki: setPartialQtyContext({ mode: 'gift', ... })
             → React-render modal gösterir, garantili çalışır.

  ▸ × İptal butonu: aynı şekilde modal'a yönlendirir.

  ▸ Yeni component: PartialQtyPicker
    - Renk teması: ikram → gold, iptal → kırmızı
    - +/- butonları (1 ile totalQty arası)
    - Hızlı seçim chip'leri
    - "Tüm qty mi seçildi?" otomatik tespit:
        - isFull = ctx.qty === ctx.totalQty
        - isFull ise partialQty parametresi gönderilmez
          (action eski full-qty akışına düşer, kalem bölünmez)
    - Backdrop'a tıklayınca kapanır
