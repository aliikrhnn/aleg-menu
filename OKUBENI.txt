ALEG TUR 9 — 3 Yeni Şablon + Özel Tasarım Yükleme
===================================================

İki büyük yenilik:

  1. 3 yeni şablon (Foto Hero, Bold Badge, Editorial)
  2. Özel tasarım yükleme + otomatik QR ekleme (yeni sayfa: /panel/menu-tasarim/ozel)


YENİ ŞABLONLAR
==============

[1] FOTO HERO (photohero)
   • Görsel 1 (Beyaz Kahve) tarzı
   • Üstte koyu mekan ambiyans alanı + ortada logo dairesi
   • Altta krem/koyu menü panel — ürünler 2 sütun
   • Ürün listesi dot leader stili (klasik à la carte)
   • Amber-gold accent rengi

[2] BOLD BADGE (boldbadge)
   • Görsel 2 (Moda Kafe) tarzı
   • Logo rozet + dev "MENÜ" tipografi
   • Ürünler 2 sütun, kategoriler ortalı uppercase
   • Alt CTA bandı turuncu accent renk
   • Modern, fast-casual

[3] EDITORIAL
   • Dergi/butik tarzı
   • Sol %32 koyu panel: tarih damgası + büyük monogram + işletme adı
   • Sağ %68: "Le Menu" başlığı + ürünler tek sütun
   • Bordo accent rengi
   • Yıllık sayı (vol.) hissi


ÖZEL TASARIM YÜKLEME — ANA YENİLİK
====================================

Yeni rota: /panel/menu-tasarim/ozel
(Ana sayfada büyük CTA banner ile yönlendirilir)

İŞLEYİŞ:
  1. İşletmeci kendi tasarladığı menüyü yükler
     • Format: PNG, JPG veya PDF
     • Maks: 8MB
     • Drag & drop veya tıklayıp seç
  2. Sistem altına otomatik QR kodu basar
  3. Konum/boyut/çerçeve ayarlanabilir:
     • Konum: alt-orta, alt-sağ, alt-sol, üst-sağ
     • Boyut: küçük (90px) / orta (130px) / büyük (180px)
     • Çerçeve rengi: beyaz / koyu (tasarımın rengiyle uyumsa diye)
     • "Dijital menü" etiketi: aç/kapat
  4. PDF/PNG indirilir — yazıcıya hazır

TEKNİK:
  • Supabase storage 'business-assets' bucket'ında
    'custom-menus/{businessId}/' altına yüklenir
  • businesses.custom_menu jsonb alanında metadata tutulur
  • Görsel yükleme: html-to-image ile kanvasa çevirip QR overlay
    eklenip indirilir (3x pixel ratio)
  • PDF yükleme: şu an PDF'i olduğu gibi gösteriyoruz (önizleme yok),
    indirmede de PDF'i indirip "altına ekle" pipeline'ı sonraki sürümde
    (gerekirse pdf-lib ile yapılır)

DB ALANLARI:
  ALTER TABLE businesses ADD custom_menu jsonb DEFAULT NULL
  
  Şema:
    {
      url: string,           -- public URL
      path: string,           -- storage path
      uploaded_at: ISO,
      filename: string,
      mime: 'image/png' | 'image/jpeg' | 'application/pdf',
      width?: number,
      height?: number
    }

SONRAKİ ADIMLAR
================

İlerleyen sürümde PDF custom menü için pdf-lib ile son sayfasına
otomatik QR şeridi eklenebilir. Şu an sadece görsel (PNG/JPG)
upload'larda canlı QR overlay çalışıyor.
