✱ DÜZELTME
──────────
deleteTable artık DB'den GERÇEK SİL yapar. Sipariş geçmişi
korunur çünkü FK constraint'leri ön tarafta doğru kurulmuş:

  TABLO              ON DELETE   ANLAM
  ─────────────────  ──────────  ────────────────────────────
  orders.table_id    SET NULL    Geçmiş siparişler kalır,
                                 sadece masa bağı kopar.
  tickets.table_id   SET NULL    Kapanmış fişler korunur.
  order_logs         SET NULL    Audit log korunur.
  waiter_calls       SET NULL    Çağrı geçmişi korunur.
  qr_codes           CASCADE     QR kod otomatik silinir
                                 (masa yoksa anlamsız).

Yani manuel temizleme yok, FK'ler kendi işini yapıyor.

✱ EKLENEN PRE-FLIGHT KONTROLLER
───────────────────────────────
1. Aktif sipariş varsa (received/confirmed/preparing/ready)
   → silmeyi reddet, "Önce siparişi tamamlayın" mesajı.
2. Açık ticket (status=open) varsa
   → silmeyi reddet, "Önce hesabı kapatın" mesajı.
3. Bekleyen waiter_calls (pending/acknowledged) varsa
   → otomatik resolve et (silinen masa için anlamsız).
