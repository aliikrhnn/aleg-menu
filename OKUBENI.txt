✱ NE YAPILDI
─────────────
Yeni kafe oluşturulduğunda sahibi geçici şifreyle giriş yapıyor.
Şu ana kadar bu şifreyle panele girip orada kalıyordu (güvensiz).
Artık ilk girişte ZORLA "yeni şifre belirle" sayfasına yönlendiriyor.
Kullanıcı yeni şifre belirlemeden panelin başka hiçbir yerine
gidemiyor.

✱ AKIŞ
──────
1. Süper admin → Yeni İşletme → form submit
   → createBusiness auth user'ı yaratırken metadata:
     must_change_password = true
2. Sahibi panel.alegstudio.com'a giriş yapar (geçici şifreyle)
3. Panel (shell) layout user.user_metadata.must_change_password
   kontrolü → true → /panel/sifre-degistir'e zorla yönlendirme
4. Kullanıcı yeni şifre + tekrar girer (en az 8 karakter)
5. Submit → changeOwnPassword action:
   - supabase.auth.updateUser({ password })
   - metadata.must_change_password = false
   - audit_log kaydı (opsiyonel, hata olursa ignore)
6. Toast "Şifren güncellendi" + /panel'e yönlendirme
7. Sonraki girişler artık doğrudan panele
