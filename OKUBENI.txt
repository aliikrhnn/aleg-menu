ALEG TUR 15 — İkram Edilmiş Geçmiş Siparişler Modal'a Sızıyor
=================================================================

SORUN
=====

Akış:
  1. Boş masaya 1 ürün ekle → ikram et
  2. Masa boşa döner ✓
  3. Aynı boş masaya tekrar bir ürün ekle
  4. ❌ Masa modal'ında daha önce ikram edilmiş ürün de görünüyor
     ("2 aktif sipariş · 2 kalem", oysa gerçekte 1 yeni sipariş var)

SEBEP
=====

getTableOrders fonksiyonu son 4 saat içindeki ödenmiş siparişleri
de getiriyor (recentlyPaidResp). Bu mantık "az önce ödenmiş, fiş
tekrar baskı için görünsün" diye eklenmişti.

Ama "tümü ikram" modunda ödenen siparişler de bu sorguya takılıyor:
  - payment_status = 'paid'
  - tüm kalemler is_complimentary = true
  - amount_paid = 0

Sonuç: Yeni sipariş + eski tamamen ikram edilmiş sipariş aynı
modal'da gözüküyor, kullanıcı şaşırıyor.

ÇÖZÜM
======

[1] getTableOrders — filtreleme:

  Tamamen ikram edilmiş + ödenmiş siparişleri modal listesinden çıkar.
  Bunlar zaten "geçmiş" — yeni masa açılışında görünmemeli.
  
  Yarısı ikram + yarısı normal ödenen siparişler kalır (fiş tekrar
  baskı için gerekli).

[2] UI sayım iyileştirmesi:

  • totalItems: artık sadece ödenmemiş + iptal edilmemiş kalemleri sayar
  • activeOrderCount: aktif kalemleri olan ödenmemiş sipariş sayısı
  • Header: "{activeOrderCount} aktif sipariş · {totalItems} kalem"
    (eski: orders.length kullanıyordu — paid+ikram dahil)
  
  Hiç aktif yok ama geçmiş varsa:
    "Aktif sipariş yok · geçmiş kayıtlar görünüyor"


KOD DEĞİŞİKLİKLERİ
==================

[1] lib/actions/tables-status.ts — getTableOrders
  • filteredOrders: tamamen ikram + paid olanları çıkar
  • formatted = filteredOrders.map(...)
  
  Filtre mantığı:
    if (payment_status !== 'paid') return true; // ödenmemişler kalır
    const activeItems = items.filter(it => status !== 'cancelled');
    if (activeItems.length === 0) return false;
    const allComplimentary = activeItems.every(it => is_complimentary);
    return !allComplimentary; // tamamen ikramsa çıkar

[2] app/kasa/table-detail-modal.tsx
  • totalItems: aktif (unpaid + non-cancelled) kalemler
  • activeOrderCount: yeni hesaplama
  • Header sayımı düzeltildi
  • "Aktif sipariş yok" durumu için yedek mesaj
