ALEG TUR 14 — İptal Edilen Kalem Total Sıfırlama (Hotfix)
============================================================

Tur 13'te iptal mantığı eklenmişti ama mevcut bozuk veri için
otomatik düzeltme yoktu. Bu turda:

  1. getTableOrders artık total'ı aktif kalemlerden hesaplar
     → DB total bozuksa otomatik doğru göstertir
  2. Tamamen iptal edilmiş ama DB'de hâlâ açık duran siparişleri
     getTableOrders sırasında lazy reconcile eder
  3. UI'da iptal edilmiş kalemler "1 KALEM" sayısına dahil değil
  4. orders.cancelled_at + cancel_reason alanları schema'ya eklendi
     (Tur 13'teki UPDATE call'larının sessiz fail etmesini önler)


SORUN ANALİZİ
==============

Ekran görüntüsünde:
  - 1× daşşak limonata İPTAL (üstü çizili görünüyor — DB'de cancelled)
  - Ama "MASA TOPLAM: ₺150" hâlâ duruyor
  - "ÖDENECEK TUTAR: ₺150"
  - "Tüm Masayı Öde · ₺150" butonu açık

Sebebi: Bu masa Tur 13 öncesi iptal edilmiş. O zamanki
cancelOrderItems action'ı total'ı düşürmüyordu. Yani
order_items.status='cancelled' ama order.total=150.

Tur 13 sadece YENİ iptaller için doğru çalışıyor, mevcut bozuk
verileri toparlamıyordu.


ÇÖZÜM: COMPUTED TOTAL
=======================

getTableOrders her seferinde toplam'ı kalemlerden hesaplar:

  // Aktif (cancelled olmayan) kalemlerden
  const computedSubtotal = activeItems.reduce(
    (s, it) => it.is_complimentary ? s : s + unit_price * quantity,
    0
  );

  // DB'deki ile farklıysa hesaplananı kullan
  const useComputed = Math.abs(dbTotal - computedSubtotal) > 0.01;

Bu sayede:
  • Tur 13 öncesi bozuk siparişler doğru görüntülenir
  • Yeni iptaller anında yansır
  • Race condition'larda da güvende


LAZY RECONCILE
================

Sipariş listesinde "tüm kalemleri iptal ama hâlâ açık" durumda
olanları arka planda otomatik kapatır:

  void admin
    .from('orders')
    .update({
      status: 'cancelled',
      cancelled_at: now,
      cancel_reason: 'Tüm kalemler iptal (reconcile)',
      subtotal: 0,
      total: 0,
    })
    .in('id', stuckIds);

  // Masada başka aktif sipariş yoksa boşalt
  await admin.from('tables')
    .update({ status: 'available' })
    .eq('id', tableId);

UI bekletilmez (fire-and-forget). Bir sonraki refresh'te masa
zaten temizlenmiş gözükür. UI hemen "boş" gösterir (stuck siparişler
filtrelenir).
