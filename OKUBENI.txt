ALEG TUR 3B — Garson + Sipariş Takip iyileştirmeleri
======================================================

3 iyileştirme:
  
  ✅ 1. Müşteri sipariş takip sayfası refresh'te durumu korur
  ✅ 2. Garson "hazırlanıyor" siparişleri için de teslim ettim diyebilir
  ✅ 3. Garson ekranında masa adı vurgulu (italic serif, 22px)


SORUN 1 — Müşteri sipariş takibi refresh'te başa dönüyor
---------------------------------------------------------

ESKİ DAVRANIŞ:
  • Müşteri sipariş takip ekranında "Hazırlanıyor"u görüyor
  • Sayfayı yeniliyor → server fetch tamamlanana kadar durum kaybolmuş gibi
    görünüyor, "Son güncelleme: şimdi" başa dönüyor

YENİ DAVRANIŞ:
  • Her status güncellemesi localStorage'a kaydediliyor
    (key: aleg-order-{orderId})
  • Refresh'te initial state localStorage'dan yükleniyor → durum korunur
  • Server'dan gelen veri ile akıllı merge: terminal durumlar (delivered/
    cancelled) kaybolmaz
  • "Son güncelleme: 2sn önce" sayacı kaldırıldı (sürekli sıfırlanıyordu)
  • Yerine sabit reassurance: "Otomatik güncelleniyor — sayfayı kapatabilir
    veya yenileyebilirsin"
  • Pulse'lı küçük noktayla canlılık veriliyor


SORUN 2 — Hazırlanıyor siparişlere "teslim ettim" yok
------------------------------------------------------

ESKİ DAVRANIŞ:
  • markOrderDelivered server action'ı sadece status='ready' kabul ediyordu
  • Garson UI'sında sadece ready siparişlerde buton görünüyordu
  • Yoğun saatte mutfak "hazır" işaretini atlamış olsa bile garson teslim
    edemiyordu — sıkışıyor

YENİ DAVRANIŞ:
  • markOrderDelivered artık 'ready', 'preparing', 'confirmed' kabul ediyor
    (sadece received/cancelled/delivered/closed reddediyor)
  • Garson kartında her durumda buton var, ama ton farklı:
    
    Ready (mutfak hazır dedi):
      → Güçlü accent buton "✓ Teslim Ettim"
    
    Preparing/Confirmed (mutfak hazır demedi):
      → İkincil ton, "⤴ Hazır olmadan teslim et"
      → Tıklayınca confirm dialog: "Mutfak hazır demeden teslim ettiğine
        emin misin?" — yanlışlık olmasın diye
  • Toast: "Sipariş teslim edildi"


SORUN 3 — Garson ekranında masa adı görünsün
---------------------------------------------

ESKİ DAVRANIŞ:
  • Masa adı vardı ama statik 16px sans-serif, gözden kaçıyordu

YENİ DAVRANIŞ:
  • Italic serif, 22px, vurgulu — Brutalist Spice tasarımıyla uyumlu
  • Sipariş kartında en görünür yer
  • Pickup → "Paket", Delivery → "Kapıya" görünür

TEST SENARYOLARI
================

[A] Sipariş takip refresh:
    1. Sipariş ver, status preparing'e geçsin
    2. Müşteri telefonunda takip ekranı açık
    3. Sayfayı yenile (Ctrl+F5)
    4. ✅ "Hazırlanıyor" durumu kaybolmaz, animasyon başa dönmez

[B] Garson "preparing" teslim:
    1. Sipariş hazırlanıyor durumda (mutfak hazır demedi)
    2. Garson sipariş kartını aç
    3. ✅ "⤴ Hazır olmadan teslim et" butonu görünmeli (ikincil ton)
    4. Tıkla → confirm dialog gelmeli
    5. Onayla → sipariş delivered, toast başarılı

[C] Garson "ready" teslim (normal akış):
    1. Mutfak hazır dedi, status=ready
    2. Garson kartı aç
    3. ✅ "✓ Teslim Ettim" butonu güçlü accent ile
    4. Tıkla → direkt teslim (onay yok, hızlı)

[D] Masa adı görünümü:
    1. Garson sipariş kartına bak
    2. ✅ Masa adı italic serif, 22px, koyu vurgulu görünmeli
    3. Paket sipariş → "Paket" yazmalı
    4. Delivery → "Kapıya"
