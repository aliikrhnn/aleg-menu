ALEG TUR 3D-v2 — Build hatası fix
==================================

ESLint/TS hatası:

  Right operand of ?? is unreachable because the left operand is never nullish.

  const statusKey = (`status_${order.status}` as keyof typeof T) ?? 'status_received';
                                                                  ^^

Template literal her zaman string döner, asla null/undefined olmaz —
TypeScript haklı, `??` gereksiz.


ÇÖZÜM
=====

Status etiketlerini T objesinden çıkarıp ayrı bir STATUS_LABELS record'una
taşıdım. Daha temiz, daha tip güvenli:

  const STATUS_LABELS: Record<string, { tr: string; en: string }> = {
    received: { tr: 'Alındı', en: 'Received' },
    confirmed: { tr: 'Alındı', en: 'Confirmed' },
    preparing: { tr: 'Hazırlanıyor', en: 'Preparing' },
    ready: { tr: 'Hazır', en: 'Ready' },
    delivered: { tr: 'Teslim edildi', en: 'Delivered' },
    cancelled: { tr: 'İptal edildi', en: 'Cancelled' },
  };

  const statusLabel = STATUS_LABELS[order.status]?.[lang] || order.status;

Artık:
  • Template literal trickery yok
  • Optional chaining (`?.`) kullanıldı — record'da olmayan status için
    de güvenli
  • Fallback (`|| order.status`) — olası yeni status isimleri için
    bilinmeyen değer dönmek yerine raw status gösterilir
