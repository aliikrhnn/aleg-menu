✱ NE DÜZELTİLDİ
────────────────

1) **FONT ÇALIŞMIYORDU — DÜZELTİLDİ**
   Önceki paket h1/h2/h3 selector'ü kullanıyordu. Ama
   menu-view.tsx'te 69 yerde `fontFamily: 'var(--f-serif)'`
   inline style olarak yazılmış, sadece 8 yer h1/h2/h3.
   Yani kuralım çoğu başlığa uygulanmıyordu.

   Düzeltme: CSS değişkeninin KENDİSİNİ override etmek.
   data-menu-font="sans" ise --f-serif: "Inter" yapıyoruz.
   Böylece 69 inline style'ın hepsi otomatik değişir.

   font preset etkisi:
     • serif    → Instrument Serif (italik başlık)
     • sans     → Inter (her yer modern temiz)
     • display  → Bricolage Grotesque (kalın display)
     • mono     → JetBrains Mono (teknik brutalist)

2) **WiFi YERİ KÖTÜYDÜ — TOPBAR'A TAŞINDI**
   Eskiden menünün ALTINDAYDI, müşteri scroll edip bulamıyordu.
   Şimdi sticky topbar olarak EN ÜSTTE.

   Görünüm:
     ┌──────────────────────────────────────────┐
     │ [📶 WIFI] [📷 INSTAGRAM] [🎵 TIKTOK] ... │ ← Sticky
     └──────────────────────────────────────────┘
            ↓ tıklayınca aşağı genişler
     ┌──────────────────────────────────────────┐
     │ AĞ ADI: Cafe-Misafir                     │
     │ ŞİFRE:  cafe2026   [DOKUN]               │
     │ [QR kod]   OTOMATİK BAĞLAN               │
     └──────────────────────────────────────────┘
     [müşteri menüsü buradan başlar]

   - Yatay scroll'lu pill button'lar (mobile dostu)
   - Tıkla → o butonun detayı topbar'ın hemen altında açılır
   - Tema rengiyle uyumlu (--accent kullanıyor)
   - Backdrop blur ile şık görünüm
