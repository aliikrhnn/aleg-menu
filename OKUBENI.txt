ALEG TUR 4C — Dashboard güzelleştirme (3. pas: HourlyChart)
=============================================================

Saatlik ciro grafiği tamamen yeniden yazıldı. Recharts dependency
kaldırıldı (artık tamamen custom SVG).


YENİLİKLER
==========

[1] Animasyonlu çizim
    • Mount'ta soldan sağa stroke-dashoffset ile çizgi "çiziliyor"
    • Area gradient aşağıdan yukarıya açılıyor
    • Heatbar bar'ları staggered (20ms aralık) bottom-up entrance
    • Peak point pop! sonra halo halkası 2.4s pulse

[2] Hover deneyimi
    • Mouse hareketinde en yakın saat noktasına snap
    • Dikey rule (kesik çizgi) o saati gösterir
    • Tooltip noktanın üstünde - dark, mono, kompakt
    • "16:00 / ₺245,00 / 12 sipariş"

[3] Görsel zenginlik
    • Background grid (ince kesik çizgiler, %50 opacity)
    • Ortalama çizgisi (yatay kesik çizgi)
    • Peak point: büyük accent dot + dış halo halkası
    • Smooth quadratic bezier path (eski monotone yerine)

[4] Heatbar yenilendi
    • "Yoğunluk haritası" başlığı eklendi
    • Bar'lar staggered animasyonla geliyor
    • Peak saat solid accent, diğerleri intensity'e göre

[5] Empty state daha sıcak
    • 🌅 ikonu yumuşak nefes animasyonu (4sn loop)
    • "Henüz sipariş yok, ama gün daha bitmedi" italic serif
    • Boş heatbar saatleri staggered entrance
    • from-to saat etiketleri altta


ÖNCESİ vs SONRASI
=================

ÖNCE: Recharts area chart, statik, hover'da basit tooltip
       Peak için sadece ReferenceDot

SONRA: Custom SVG animasyonlu chart
       • Mount entrance animasyonu (1.2s çizim)
       • Dikey hover rule + büyük circle highlight
       • Peak halkası pulse loop
       • Ortalama referans çizgisi
       • Heatbar staggered entrance


BUNDLE BOYUTU
=============

Önceden recharts'tan AreaChart, Area, XAxis, YAxis, ResponsiveContainer,
Tooltip, ReferenceDot import ediliyordu.

Şimdi: sadece React + next/link. Recharts hâlâ başka yerlerde
kullanılabilir (rapor sayfaları gibi) — onları etkilemez.
