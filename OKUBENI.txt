ALEG TUR 3C — Multi-order takip + Google yönlendirme debug
============================================================

İki sorun:

  ✅ 1. Aynı masada birden fazla sipariş olduğunda karışıyordu
        → Müşteri bir siparişi takip ederken aynı masaya verilen DİĞER
          siparişleri de görüp aralarında geçiş yapabilecek
  
  ✅ 2. 4-5 yıldızda Google'a yönlendirmiyordu
        → Cache stratejisi sadeleştirildi (settings her zaman taze)
        → Console.log eklendi - sebebi tespit etmek için


SORUN 1 — Multi-order karışıklık
=================================

ESKİ DAVRANIŞ:
  • Her sipariş kendi UUID URL'inde: /menu/[slug]/siparis/[orderId]
  • Aynı masaya 2 sipariş veren müşteri 1. siparişin URL'ini takipte tutsa
    bile 2. siparişin durumunu o ekranda görmüyordu
  • Garson 1. siparişi teslim edince ekran "delivered + review" gösteriyor,
    2. sipariş hâlâ hazırlanıyor olduğu halde müşteri için kayboluyordu

YENİ DAVRANIŞ:
  • getOrderTracking artık aynı masaya verilen son 6 saatlik tüm
    siparişleri "related_orders" olarak da döndürüyor
  • Tracking ekranında sipariş kalemleri altında "Bu masadaki diğer 
    siparişlerin" bloğu görünüyor:
    
      📋 #A1B2C3D4  ALINDI       5 dk · ₺145
      🍳 #E5F6A7B8  HAZIRLANIYOR  2 dk · ₺85
      ✓  #C9D0E1F2  TESLİM        1 sa · ₺220
      
  • Her satır o siparişin kendi takip URL'ine link
  • Status renkli (alındı=ink, hazırlanıyor=accent, hazır/teslim=olive,
    iptal=danger)
  • Tek aktif sipariş varsa blok hiç görünmüyor (gereksiz UI yok)


SORUN 2 — Google yönlendirme çalışmıyor (debug)
================================================

OLASI NEDENLER:
  [a] Panel → Yazıcılar & Fiş → Fiş Tasarımı'nda
      "Akıllı yönlendirme" toggle KAPALI
  [b] Google Place ID alanı BOŞ (toggle açık olsa bile)
  [c] Browser eski JavaScript bundle'ı cache'lemiş
  [d] Tur 3B'den kalan localStorage cache eski formatta

İLERİ ALMAK İÇİN:
  • Müşteri telefonunda takip ekranını aç
  • Yıldıza tıkla
  • Browser console'una bak — şu log'u göreceksin:
  
    [Aleg Review] {
      stars: 5,
      smartRedirect: true,    ← false ise Panel'de toggle kapalı
      hasPlaceId: true,        ← false ise Google Place ID girilmemiş
      placeId: 'ChIJ...'
    }
  
  • smartRedirect false ise → Panel'de toggle aç
  • hasPlaceId false ise → Google Place ID gir
  • İkisi de true ama yine yönlendirmiyorsa → screenshot al, console
    log'u paylaş

CACHE TEMİZLEME:
  • Tur 3B'de localStorage'a TÜM order objesi kaydoluyordu (review settings
    olmadan kayıt edilmiş eski cache'ler smart_redirect=undefined dönüyor
    olabilir)
  • Tur 3C'de cache stratejisi değiştirildi:
    - Eski key: aleg-order-{uuid}      → JSON.stringify(tüm obje)
    - Yeni key: aleg-order-status-{uuid}  → sadece status string
  • Eski cache'ler ilk açılışta otomatik temizleniyor
  • Settings (review_smart_redirect, google_place_id) ARTIK CACHE'TE YOK,
    her zaman server'dan geliyor
  
  Yine de browser cache sorunluysa müşteri telefonundan:
    • Ayarlar → Tarayıcı → Site verilerini temizle
    • veya Hard refresh: iOS Safari'de Settings → Safari → Clear History

TEST SENARYOLARI
================

[A] Multi-order:
    1. Aynı masaya farklı 2 sipariş ver (A=2 ürün, B=3 ürün)
    2. A'nın takip URL'ini aç
    3. ✅ "Bu masadaki diğer siparişlerin" altında B görünmeli
    4. B'ye tıkla → B'nin takip ekranı açılmalı
    5. Orada da "Bu masadaki diğer siparişlerin" altında A olmalı
    6. Garson A'yı teslim et → A'nın ekranı review formuna geçer
    7. B'nin ekranında A "Teslim ✓" olarak görünür ama B hala hazırlanıyor

[B] Google yönlendirme:
    1. Panel → Yazıcılar & Fiş → Fiş Tasarımı
    2. "Akıllı yönlendirme" toggle AÇ
    3. Google Place ID gir (örn: ChIJN1t_tDeuEmsRUsoyG83frY4)
    4. Kaydet
    5. Müşteri sipariş ver, delivered durumuna gelsin
    6. Takip ekranında 5 yıldıza tıkla
    7. Console'da "[Aleg Review]" log'u kontrol et
    8. ✅ "Bunu duymak harika!" + Google butonu görünmeli
    9. Google butonuna tıkla → yeni sekmede Google review sayfası

[C] Düşük yıldız (1-3):
    1. Aynı sipariş için 2 yıldıza tıkla
    2. ✅ Direkt yorum formu açılmalı (Google ekranı atlanıyor)
    3. "Ne oldu?" prompt'u görünmeli
    4. Yorum yaz, gönder
    5. ✅ Sadece panele düşmeli, Google'a yönlendirme YOK
