Paket 4 - BUILD FIX 3 (Database types cast)
============================================

Bu fix turu sadece 6 server action dosyasını günceller.
Component dosyaları (önceki fix-2'deki halleri) AYNEN KALACAK.

SORUN: 
  Yeni eklediğim tablolar (support_tickets, platform_announcements,
  platform_settings) henüz @/types/database'de tanımlı değil.
  Bu yüzden insert/update'ler "argument is not assignable to never"
  hatası veriyordu.

ÇÖZÜM:
  Her server action dosyasının başına UntypedSupabase tip alias'ı
  eklendi. createClient() çağrılarına `as unknown as UntypedSupabase`
  cast yapıldı. Böylece TypeScript yeni tabloları görmediğinde
  sorun çıkarmıyor; runtime'da hiçbir fark yok çünkü Supabase 
  client zaten tüm tabloları biliyor.

  İLERİDE: Database types'ı yeniden generate ettiğinde
  (`yarn supabase gen types typescript --project-id ... > types/database.ts`),
  bu cast'leri kaldırabilirsin.
