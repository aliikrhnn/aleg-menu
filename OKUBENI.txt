=============================================================

Popüler ürünler kartı tamamen yenilendi. #1 ürün hero treatment +
animasyonlu sıralama listesi.


YENİLİKLER
==========

[1] Champion Card (#1 en çok satan)
    • Üstte özel kart: subtle gold/accent gradient background
    • Sağ üstte "sparkle glow" radial pulse animasyonu (3s loop)
    • Sol: ürün görseli (hero_image_url) > emoji (hero_icon) > ★ fallback
      → 56x56 yuvarlak kenarlı thumbnail
    • Ortada: 🥇 1. badge + ürün adı (italic serif 22px) + adet/ciro
    • Mount entrance animation (spring scale + fade)

[2] Sıralama satırları (2-5)
    • Numaralı badge (silver/bronze tonları)
    • Mini thumbnail (emoji veya image varsa)
    • Bar fill animasyonu — 0'dan değere staggered (80ms aralık)
    • Hover'da hafif paper-2 background

[3] Backend genişletildi
    • Top ürün ID'leri toplanıyor
    • products tablosundan hero_icon ve hero_image_url çekiliyor (tek query)
    • topProducts dizisinde her ürünle birlikte dönüyor

[4] Empty state daha şirin
    • ☕ emoji 3s loop'ta yumuşak bob (sallanma)
    • "İlk sipariş geldiğinde..." italic serif


ÖNCESİ vs SONRASI
=================

ÖNCE: Tek tip 5 satır, basit progress bar
SONRA:
  • #1 → büyük hero card (görsel + serif italic + badge + glow)
  • #2-#5 → kompakt liste, bar staggered fill, mini thumbnail


BACKEND DEĞİŞİKLİKLERİ
======================

DashboardData.topProducts tipi:
  ÖNCE: { product_id, product_name, quantity, revenue }
  SONRA: ... + hero_icon: string | null, hero_image_url: string | null

dashboard.ts:
  • topProductIds çıkarılıyor
  • products tablosundan hero alanları batch query ile çekiliyor
  • topProductsWithHero dizisi dönüş objesinde
