[2] app/panel/(shell)/vardiya/staff-list.tsx (YENİ)
    İnteraktif personel CRUD UI:
    
    • Header: "EKİP · VARDİYA" eyebrow + "Personel ve vardiya." başlığı
    • "Yeni Personel" butonu (sağ üst, accent rengi)
    • Aktif personel grid (3 kolon @ desktop, 2 @ tablet, 1 @ mobile)
    • Pasif personel ayrı grid (opacity 60%)
    • Empty state — hiç personel yoksa CTA göster

    • Avatar (rol rengi + initial harfler) — manager kırmızı,
      barista yeşil, server mavi, kitchen sarı

    • Telefon (varsa)
    • Saatlik ücret (varsa)
    • [Düzenle] [Pasifle / Aktif Et] butonları
    • Pasifte: [×] kalıcı sil butonu (sadece vardiyası yoksa)
    
    Modal:
    • Yeni personel + düzenleme aynı modal (mode prop)
    • Ad (zorunlu, min 2 karakter)
    • Rol toggle (4 buton, seçilen renkli)
    • Telefon (opsiyonel)
    • Saatlik ücret (opsiyonel, 0-10.000 ₺)
    • ESC ile kapanma
    • Backdrop tıklama ile kapanma

TEST
=====

[A] SAYFA AÇILIYOR MU:
    1. panel.alegstudio.com/vardiya  (sidebar'da menü yok henüz, URL'i elle yaz)
    2. ✅ Sayfa yüklenmeli, "EKİP · VARDİYA" başlık görünmeli
    3. ✅ Boş durum: "Henüz personel yok" + CTA buton

[B] PERSONEL EKLE:
    1. "+ Yeni Personel" tıkla
    2. Modal açılır → Ada Yılmaz, Barista, 0555..., 120 yaz
    3. "Ekle" → toast "Ada Yılmaz eklendi"
    4. ✅ Aktif Personel · 1 başlığı altında kart görünür

[C] DÜZENLE:
    1. Personelin "Düzenle" butonu
    2. Modal açılır, mevcut bilgiler dolu
    3. Saatlik ücreti değiştir, "Kaydet"
    4. ✅ Kart güncellenmeli

[D] PASİFLE:
    1. "Pasifle" → onay modali → Pasifle
    2. ✅ Kart "Pasif Personel" başlığı altına geçer (opacity 60%)
    3. Pasifte "Aktif Et" görünür

[E] SİL:
    1. Önce pasif yap
    2. [×] kalıcı sil butonuna bas
    3. ✅ Onay sonrası tamamen kaybolur
    4. Eğer vardiyası varsa "Bu personelin vardiya kayıtları var" hatası çıkar

[F] SIDEBAR'DA MENÜ YOK — Paket 4'te eklenecek
    Şu an URL'i elle yazıp test ediyorsun.
