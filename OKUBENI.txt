ALEG TUR 17d — Müşteri Menü: Kalan "Sepete Ekle" + Çağrı Butonu Çakışma
=========================================================================

İki düzeltme:

  1. Ürün seçim modal'ında (varyasyonlu ürün) "Sepete Ekle" hâlâ
     görünüyordu → "Masaya Ekle" olarak güncellendi
  2. "SİPARİŞLERİM" floating badge'i ile çağrı butonu üst üste
     biniyordu → çağrı butonu siparişlerim üstüne kaydırıldı


[1] OPTIONPICKER MODAL - SEPETE EKLE
======================================

ÖNCESİ (kalmış):
  Ürüne tıkla → varyasyon seç modalı açılır
  Footer butonu: [Sepete Ekle  ₺250]

SONRASI:
  [Masaya Ekle  ₺250]    (TR)
  [Add to Table  ₺250]   (EN)

Ayrıca eksik olan dil desteği eklendi (eskiden hardcoded TR'di).


[2] ÇAĞRI BUTONU ÇAKIŞMA
==========================

SORUN (kullanıcı görüntüsü):
  ┌──────────────────────────────┐
  │                              │
  │                              │
  │                              │
  │              [✋ ÇAĞRI]      │ ← bu görünmüyor
  │       [📋 SİPARİŞLERİM (1)]  │ ← bu üstüne biniyor
  └──────────────────────────────┘

Çağrı butonu: right:16, bottom:24
Siparişlerim:  right:16, bottom:16 (yüksek 48px)
→ Üst üste binmiş

ÇÖZÜM:
  Çağrı butonu konum mantığı yenilendi:
  
  • cart YOK + siparişlerim YOK     → bottom: 24
  • cart YOK + siparişlerim VAR     → bottom: 84  ← yeni
  • cart VAR + scroll yok           → bottom: 84
  • cart VAR + scroll çok           → bottom: 144
  • cart YOK + siparişlerim VAR + scroll çok → bottom: 144

Sonuç:
  ┌──────────────────────────────┐
  │                              │
  │                              │
  │              [✋ ÇAĞRI]      │ ← üstte
  │       [📋 SİPARİŞLERİM (1)]  │ ← altta
  └──────────────────────────────┘
  
  Her iki buton da tıklanabilir.


KOD DEĞİŞİKLİĞİ
================

[1] app/menu/[slug]/menu-view.tsx

  - OptionPickerModal footer butonu:
    "Sepete Ekle" → "Masaya Ekle" (TR/EN ayrımıyla)

  - Çağrı butonu bottom hesabı:
    Önceki:
      bottom: cartCount > 0
        ? (scrollY > 600 ? 144 : 84)
        : (scrollY > 600 ? 84 : 24)

    Sonraki:
      bottom: (() => {
        const hasFloatingMyOrders = cartCount === 0 && myOrdersCount > 0;
        if (cartCount > 0) return scrollY > 600 ? 144 : 84;
        if (hasFloatingMyOrders) return scrollY > 600 ? 144 : 84;
        return scrollY > 600 ? 84 : 24;
      })()
