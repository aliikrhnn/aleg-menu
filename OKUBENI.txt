ALEG — Tema Önizleme 404 Fix
==============================

SORUN
======
Panel → Ayarlar → Tema → Önizleme:
  "404 Burada bir şey yok"

SEBEP
======
Subdomain refactor sonrası /menu/[slug] rotası
panel.alegstudio.com'da yok. Müşteri menüsü artık sadece
[slug].alegstudio.com'dan erişilebilir.

Theme preview iframe'i hâlâ eski path-based URL kullanıyordu:
  /menu/${slug}?preview_theme=...
  → 404


YAPILAN
========

app/panel/(shell)/ayarlar/tabs/theme-preview.tsx
  • previewUrl artık subdomain URL kullanır:
    https://${slug}.${rootDomain}/?preview_theme=...
  • Iframe subdomain'leri sorunsuz açar (modern CORS değil)


PUSH
=====

  git add app/panel/\(shell\)/ayarlar/tabs/theme-preview.tsx
  git commit -m "fix: tema önizleme subdomain URL kullansın (404 fix)"
  git push origin main


TEST
=====

  1. Panel → Ayarlar → Tema → Önizleme
  2. ✅ Müşteri menüsü iframe'de görünür
  3. Tema değiştir → ✅ iframe yeniden yüklenir, tema değişir
