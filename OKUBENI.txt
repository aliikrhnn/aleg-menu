✱ NE DEĞİŞTİ — FEATURE 2: ADET BAZLI İKRAM/İPTAL
─────────────────────────────────────────────────
Önceden "2× Ice Latte" tek satırdı, ikram/iptal hep tüm grubu
işliyordu. Şimdi her adet ayrı satır olarak gözüküyor:

    ☐ 1× Ice Latte #1/2          ₺95
    ☐ 1× Ice Latte #2/2          ₺95

Kullanıcı 1'ini seçip ikram, diğerini iptal edebilir.
Veya 1'ini ikram, kalan 1'i normal ödeyebilir.

⚠ Para tutarsızlığı olmaması için: aynı kalemden KISMİ seçim
varken (ör. 2'den sadece 1) → "Seçili Öde" / "Parçalı" / "Açık
Hesap" butonları kapalı kalıyor. Üstte "⚠ KISMİ SEÇİM" altın
badge'i çıkıyor. Önce ikram/iptal ile ayır, sonra öde.

✱ DEĞİŞİKLİK ÖZETİ
──────────────────
hesap-panel.tsx — TAM EKRAN:
  • Modal: max-w-[1400px] → max-w-none + height calc(100vh - 0.5rem)
  • Outer padding: p-2 sm:p-4 → p-1 sm:p-2
  • Sol kalemler: flex-1 → lg:w-[480px] xl:w-[560px]
  • Sağ menü: lg:w-[380px] sabit → lg:flex-1

hesap-panel.tsx — ADET BAZLI:
  • FlatItem tipi: subIndex + parentQuantity alanları
  • flatItems: her item quantity adet sanal alt-satıra bölünüyor
  • Selection key: orderId__itemId__subIndex (sanal key)
  • itemRollups helper: virtual seçim → parent kaleme rollup
  • hasPartialRollup flag: kısmi seçim → ödeme akışları kapalı
  • İkram (handleGiftSelected): rollup + partialQty server desteği
  • İptal (handleCancelSelected): rollup + partialQty server desteği
  • Ödeme (Seçili / Parçalı / Açık Hesap): kısmi seçim → toast uyarı
  • UI: "2× Item" → "1× Item #1/2" gösterimi
  • Header: "1/4 seçili" + kısmi seçim badge

menu-picker.tsx:
  • Ürün gridi: grid-cols-2 → grid-cols-2 xl:grid-cols-3 2xl:grid-cols-4

NOT: Server tarafına HİÇ DOKUNULMADI. makeItemsComplimentary ve
cancelOrderItems action'ları zaten partialQty parametresini
destekliyordu, sadece UI kullanmıyordu. Şimdi kullanıyor.
