SORUN
=====

  ./app/panel/(shell)/raporlar/islem-gecmisi/client.tsx:494:23
  Type error: Type 'unknown' is not assignable to type 'ReactNode'.

log.details.productName tipinde 'unknown' (jsonb'den geliyor).
JSX'te bunu doğrudan koşul olarak yazınca render çıktısı 'unknown'
oluyor, ReactNode değil.

ÇÖZÜM
=====

Truthy kontrolünü Boolean() ile sarmalayarak ReactNode döndürdüğü
kesinleştirildi:

  // ÖNCE (hata):
  {log.details.productName && <span>...</span>}

  // SONRA:
  {Boolean(log.details.productName) && <span>...</span>}

Aynı şekilde reason için ternary -> Boolean dönüştürüldü.
