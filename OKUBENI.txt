YAPILAN
========

[1] package.json + package-lock.json
   • web-push@^3.6.7 dependencies'e eklendi
   • @types/web-push@^3.6.4 devDependencies'e eklendi
   • npm install çalıştırıldı, lockfile güncellendi

[2] lib/security/web-push.ts (YENİ)
   • Server-side push gönderme helper
   • VAPID env variable'larını okur
   • sendPushToBusiness(businessId, role, payload)
     → Bir işletmenin tüm garsonlarına/kasiyerlerine bildirim
   • sendPushToCashier(cashierId, payload)
     → Belirli bir cashier'in tüm cihazlarına bildirim
   • Otomatik expired subscription temizliği (410/404 alınca)
   • last_used_at güncellemesi (background)
   • getVapidPublicKey() — client'a public key vermek için

[3] lib/actions/push-notifications.ts (YENİ)
   • getPushPublicKey() — VAPID public key client'a verir
   • savePushSubscription({endpoint, p256dh, auth})
     → Kullanıcı izin verdikten sonra subscription'ı DB'ye kaydeder
     → Cashier session zorunlu
     → Aynı endpoint için upsert (token rotation desteği)
   • deletePushSubscription(endpoint)
     → Çıkış yapınca subscription siler
   • sendTestPush() — kendi cihazına test bildirimi
     → Subscribe akışını test etmek için kullanılır

[4] public/sw.js (YENİ)
   • Service worker — client tarafında çalışır
   • install/activate lifecycle
   • push event handler — bildirim göster
   • notificationclick — tıklayınca uygulamayı aç (veya odakla)
   • pushsubscriptionchange — token yenileme
   • Logging için SW_VERSION = 'v1.0.0'

[5] BONUS — app/api/manifest/garson/route.ts + kasa
   • Cache-Control: max-age=300 → max-age=60, must-revalidate
   • Logo değişiklikleri 60 saniyede yansır (5dk yerine)
