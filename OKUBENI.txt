ALEG TUR 8 — Migration düzeltmesi (text[] uyumlu)
====================================================

SORUN
-----

Migration çalıştırırken hata:
  ERROR: column "dietary_tags" is of type text[] but expression is of type jsonb

Sebep: dietary_tags kolonu daha önceden text[] (PostgreSQL native array)
olarak oluşturulmuş. Migration ise jsonb değer atamaya çalışıyordu.

ÇÖZÜM
-----

Migration text[] tipiyle uyumlu hale getirildi:
  • dietary_tags text[] DEFAULT '{}'::text[]   (jsonb yerine)
  • UPDATE'lerde '{}'::text[] kullanıldı

==========

hiçbir şey değişmedi. Sadece migration düzeltildi.
