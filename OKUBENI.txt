ALEG TUR 5 — QR Menü Tema Kişiselleştirme
==========================================

İşletme sahibi panelden 5 farklı tema seçebilir + accent rengi
özelleştirebilir. Müşteri menüsü (slug.alegstudio.com) bu seçime
göre render olur.


5 TEMA
======

1. BRUTALIST SPICE (default - şu an kullanıyoruz)
   Paper #FAF5EA, Ink #2A1F18, Accent #C4553A
   Bricolage + Instrument Serif italic
   Sıcak, karakter dolu

2. ELITE RESTORAN
   Paper #1A1814 (koyu!), Ink #F2EAD8, Gold #C9A961
   Playfair Display + Cormorant Garamond
   Lüks fine dining, sert köşeler (4px radius)

3. MODERN CAFE
   Paper #FFFFFF, Ink #0A0A0A, Mint #4ABDAC
   Inter + Crimson Pro + JetBrains Mono
   Temiz, çağdaş, contemporary

4. VINTAGE BISTRO
   Paper #F8F0E3, Ink #3D2817, Deep red #8B2635
   DM Serif Display + Lora + Courier Prime
   Eski Paris kafesi havası, neredeyse köşeli (2px radius)

5. MINIMAL SKANDINAV
   Paper #FAFAFA, Ink #2C2C2C, Sage #B7C4A0
   Inter (serif yerine de) - Söhne fallback
   Soğuk, sade, Nordic, küçük harf eyebrow'lar


ÖZEL ACCENT RENGİ
=================

İşletme sahibi 10 önerilen renkten seçebilir VEYA özel hex girebilir
(#RRGGBB). Bu seçim temanın varsayılan accent rengini override eder.
Yani "Modern Cafe" tema + kendi marka rengi = işletmeye özel his.

Önerilen renkler:
  • Brutalist accent (#C4553A)
  • Gold (#C9A961)
  • Mint (#4ABDAC)
  • Deep red (#8B2635)
  • Sage (#B7C4A0)
  • Ocean blue (#1F4E5F)
  • Dusty purple (#7A5C9F)
  • Terracotta (#D97757)
  • Emerald (#0F766E)
  • Amber brown (#92400E)


PANEL UI
========

Yeni tab: "Menü Teması" (Sipariş ile Bildirim Sesleri arası)

3 adımlı flow:
  Adım 1: Tema seç
    • 5 büyük kart, gerçek tema renkleriyle mini önizleme
    • Seçilende sağ üstte ✓ + ink border + scale
  
  Adım 2: Vurgu rengi
    • "Varsayılan" + 10 renk + "Özel" butonu
    • Özel'e tıklayınca color picker + hex input
    • Seçilen renkte ink border + scale
  
  Adım 3: Önizleme
    • Browser-style mockup (3 nokta + URL + tema adı)
    • Gerçek tema renkleriyle örnek menü:
      - Hero başlık + tagline + sipariş ver butonu
      - "Kahveler" kategorisi (3 ürün)
      - "Tatlılar" kategorisi (2 ürün)
      - Footer
    • Tema değiştirince anında güncelleniyor


VERİ MODELİ
===========

Yeni kolon: businesses.menu_theme (jsonb)

  {
    "preset": "brutalist" | "elite" | "modern" | "vintage" | "minimal",
    "accent_override": "#C4553A" | null
  }

Default: { preset: "brutalist", accent_override: null } (mevcut davranış)


MÜŞTERİ MENÜSÜ TARAFI
=====================

app/menu/[slug]/page.tsx içinde:
  1. businesses.menu_theme okunur
  2. resolveTheme() ile preset + accent çözülür
  3. buildThemeCSS() ile [data-menu-theme] scope'lu CSS üretilir
  4. <style> tag'iyle inject edilir
  5. <div data-menu-theme="elite"> ile MenuView sarılır

Sonuç: var(--paper), var(--ink), var(--accent), var(--f-serif) vb. tüm
CSS değişkenleri tema'ya göre yazılır. MenuView ve içindeki tüm
component'ler (cart-drawer, my-orders-panel, ürün kartları) otomatik
olarak yeni tema renklerini ve fontlarını kullanır.

Hiçbir component kodu değiştirilmedi — sadece CSS variable'lar.


FONTLAR
=======

globals.css'e eklenen Google Fonts importları:
  • Bricolage Grotesque (zaten vardı)
  • Instrument Serif (Brutalist)
  • Playfair Display + Cormorant Garamond (Elite)
  • Inter + Crimson Pro + JetBrains Mono (Modern)
  • DM Serif Display + Lora + Courier Prime (Vintage)
  • Söhne yok → Inter fallback (Minimal)
