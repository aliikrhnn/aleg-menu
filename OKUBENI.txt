YAPILAN
========

[1] AI altyapısı
    • lib/ai/claude.ts → generateNutritionInfo() eklendi
      - Haiku 4.5 model (ucuz, alerjen sınıflandırma için yeter)
      - 14 ana alerjen (EU 1169/2011 standardı)
      - Konservatif yaklaşım (emin değilsen işaretle)
      - JSON output, robust parse + validation
      - TR + EN içerik listesi otomatik üretir
      - Bonus: typo fix ("Turkish and Turkish" → "Turkish and English")

    • lib/ai/rate-limit.ts → 'nutrition' feature eklendi
      - Günde 200 ürün analizi (toplu doldur için)

[2] Server actions (lib/actions/ai.ts)
    • aiGenerateProductNutrition()
      - Tek ürün için AI üretir + DB'ye yazar
      - Mevcut bilgi varsa overwrite onayı ister
      - nutrition_ai_generated=true flag set eder
      - Verify ZORUNLU DEĞİL (kullanıcı tercihi — direkt görünür)

    • aiGenerateNutritionForAllProducts()
      - Toplu mod: 'missing' (sadece eksikler) veya 'all' (hepsi overwrite)
      - Max 50 ürün (config 200'e kadar)
      - Tek tek işler, 200ms throttle (API stress önler)
      - Rate limit doluysa kalanları atlar

    • updateProductNutrition()
      - Manuel form düzenleme + kaydet
      - markAsVerified=true → işletmeci doğruladı flag'i

[3] Panel UI — Ürün listesi
    • Her ürün satırına "🍎 Beslenme" butonu eklendi
      - Bilgi yoksa ⚠ uyarısı
      - Bilgi varsa accent renk
    • Üstte "✨ Beslenme Bilgisi (X)" toplu doldur butonu
      - X = eksik ürün sayısı
      - 0 olursa buton gizlenir
      - Sonuç banner'ı (X işlendi · Y hata · Z atlandı)

[4] Panel UI — Beslenme modal'ı (NutritionEditModal)
    • Header: ürün adı + AI rozeti
    • [✨ AI ile doldur] büyük buton
    • 14 alerjen chip seçici (emoji + TR ad)
    • Kalori (kcal) + Porsiyon yan yana input
    • İçerik TR + EN textarea (markdown ** desteği)
    • Alkol toggle (18+)
    • AI notu (varsa) gösterilir
    • Kaydet / Vazgeç
